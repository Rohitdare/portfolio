# Trainer ID Portfolio

A personal developer portfolio themed around an anime-inspired Trainer ID badge, built with **Next.js**, **React**, and **TypeScript**.

## ✨ Features

- **3D Trainer ID Badge:** Interactive 3D card tilt physics, specular sheen, and lanyard assembly.
- **Section Navigation:** Home, Tech Stack, Projects, Experience, Blog, and Contact with instant hash routing.
- **Interactive Background:** Dynamic dot-grid matrix on HTML5 Canvas with proximity glow.
- **Oneko Companion:** Interactive cat sprite that follows cursor and can be dragged around.
- **Battle Mode:** Easter egg final battle overlay.
- **Audio Effects:** Synthesized Web Audio API sound effects.
- **Dual Theme:** Light and dark mode support with instant theme switching.
- **GitHub Heatmap:** Contribution grid with live API sync and offline cache.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React 19 + TypeScript
- **Styling:** Vanilla CSS (CSS Variables / Design Tokens)
- **Audio:** Web Audio API

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Rohitdare/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Building for Production

```bash
npm run build
npm run start
```
